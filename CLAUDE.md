# Instruções para o Claude

## Sincronização

Este projeto é usado em sessões na nuvem e também numa cópia local, em outro computador, que se atualiza sozinha a partir da branch `main`.

- Ao terminar cada tarefa, faça commit e push **direto na branch `main`**. Não abra pull request e não deixe o trabalho só em outra branch.
- Antes de começar, rode `git pull` para partir da versão mais recente.
- Se o push for recusado porque a `main` mudou, faça `git pull --rebase` e tente de novo.
